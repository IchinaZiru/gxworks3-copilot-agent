# GX Works3 AI Agent PoC / 初回プロンプト

GX Works3を自然言語で操作するAIエージェントのPoCを進めます。

目的: 初心者がGX Works3の基本操作を自然言語で実行できるか検証する。
技術: VS CodeのローカルCopilot harnessとComputer Useを優先。
実装は標準ツールで始め、独自RAG・MCPは当面作らない。

工程: (1)環境確認 (2)画面認識 (3)新規プロジェクト作成 (4)保存 (5)マニュアル参照 (6)検証済み操作のSkill化 (7)簡易ラダー編集 (8)評価。

制約: オフラインのテストプロジェクトのみ使用し、PLC実機への接続・書き込み・運転は禁止。事前確認のない上書きも禁止。不明な画面や設定では停止して確認。

まず実装案と環境条件を整理し、OS・GX Works3版・CPU機種・Copilot契約/権限・Computer Useの利用可否・マニュアル参照可否を確認してください。GUI操作やファイル更新は私の承認後に実施してください。
