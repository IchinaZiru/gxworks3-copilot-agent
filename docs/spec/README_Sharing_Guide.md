# 社内PCへの持ち込み／共有手順（案）

この文書は外部環境で作成した事前検討ドラフトです。社内のセキュリティ・データ持込規程を確認してから使用してください。

## 推奨
1. 社内で承認済みの SharePoint/Teams/OneDrive のドキュメントライブラリを使用します。外部からのアップロード許可を確認し、社内アカウントでアクセスできる場所に置き、閲覧対象を社内メンバーに制限します。
2. 許可された社内 Git リポジトリがあれば、Markdown と PDF を登録し、社内PCから取得します。
3. 承認済みのメール添付やファイル転送経路があれば利用します。

## やらないこと
- 社内非公開情報を公開GitHub/Gist、公開Web、個人クラウドのリンク公開設定に置かない。
- 社内PCで禁止されているクラウド・ChatGPTアクセス制限を回避しない。
- このチャットの sandbox ダウンロードリンクを永続公開URLとみなさない。

## ファイルの選び方
- PDF: 周知・閲覧・配布向け
- DOCX: 社員との共同レビュー・修正向け
- Markdown: VS Code Copilotにコンテキストとして与える用途
- Copilot_Initial_Prompt.md: 社内PC上でCopilotへ最初に渡す文章
