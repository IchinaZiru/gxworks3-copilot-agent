## 前提
- GX Works3が起動している
- 実機PLCと接続していない
- 既存の業務用プロジェクトを開いていない

## 公式教材に基づく基本手順
1. GX Works3の「プロジェクト」から「新規作成」を開く。
2. 新規作成画面で、担当者が指定したCPU機種とプログラム言語（今回の検証では「ラダー」）を選択する。
3. 表示された条件を確認して「OK」を選ぶ。
4. 続くユニットラベル・サンプルコメント等の設定画面が出た場合は、実習指定の設定を確認してから進む。指定がなければ勝手に決定せず一旦停止する。
5. 新しいプロジェクトの画面とCPU機種を確認する。

## 成功判定
- 新規テストプロジェクトが開いている
- 指定されたCPU機種・プログラム言語が一致する
- 実機への書き込みや通信が行われていない

## 停止条件
- CPU機種や各初期設定の指定がない
- 既存プロジェクトの上書き確認や想定外のダイアログが出た
- 画面の選択肢がマニュアルと異なる
