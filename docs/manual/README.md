# マニュアルの置き方

この `docs/` は、GX Works3の操作手順をCopilotに与えるためのフォルダです。
`01_project.md` は公式教材に基づく基本手順です。`02_save.md`、`03_ladder.md` は**記入用のひな形**であり、完成したマニュアルではありません。

## 記入ルール

- 一操作につき一つの目的、必要な事前状態、番号付き手順、成功判定、失敗時の中断条件を記入
- GX Works3のバージョン / CPU機種 / マニュアル名 / 該当章・ページを記入
- 画面に表示される正式なメニュー名、クリック順を記入
- スクリーンショットがある場合は、公開やAI入力の許可を確認してから利用
- 社内非公開の資料を使う場合は、生成AIに入力してよいか社内承認を得る

## 参照時の注意

Copilotは `docs/` 内の全ファイルを毎回自動的に全文参照するとは限りません。
具体的な作業時には、必要なファイルをチャットに明示的に添付してください。

**注意:** Publicリポジトリには公開を許可された手順だけを収録し、社内マニュアル本文や社内画面のコピーは別途許可された保管場所に置いてください。
